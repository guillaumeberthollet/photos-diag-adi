Token de connexion Dropbox

Page d'administration, à utiliser une seule fois sur un ordinateur. Elle produit un token de connexion longue durée à coller dans l'écran « Configuration » de chaque téléphone.

Connectez-vous avec le compte Dropbox qui doit recevoir les photos.

Token de connexion

Copiez-le, puis collez-le sur chaque téléphone. Ne le publiez nulle part : il donne le droit d'écrire dans le dossier Dropbox de l'appli. En cas de fuite, révoquez-le depuis les réglages Dropbox (Applications connectées).
